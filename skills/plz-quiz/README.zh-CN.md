# plz-quiz
[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | 简体中文

用自己的资料生成测验，边答题边学习，或在查看答案前检查学习效果。支持 Claude Code 和 Codex，是 [plz](../../README.md) 的一部分。

## 安装

以下命令需要此技能已在仓库中发布。要试用本地草稿，可以让代理直接读取 `skills/plz-quiz/SKILL.md`。

全局安装：

```sh
npx skills add codekongdev/plz --skill plz-quiz -g
```

在 Codex 中使用时加上 `-a codex`。以下命令安装到当前项目的 `.agents/skills/` 目录：

```sh
npx skills add codekongdev/plz --skill plz-quiz -a codex
```

## 使用方法

提供文档或粘贴笔记，然后用你希望使用的语言请求测验。

Claude Code:

```text
/plz-quiz Quiz me on these notes, one question at a time.
```

Codex:

```text
$plz-quiz Quiz me on these notes, one question at a time.
```

请求示例：

- “根据这份 PDF 的第 2 章出十道选择题。”
- “检查我是否理解了这份文档。答完之前不要显示答案。”
- “多出一些应用概念的题目，不要只考术语记忆。”
- “针对我答错的概念，换一些新题让我再做一次。”

## 学习与学习检查模式

- **学习：** 每次回答一道题，然后查看判定、简短解析和资料依据。需要时可以请求提示。
- **学习检查：** 提交完答案后再查看分数、正确答案和解析。遗漏的答案会在评分前确认；“不知道”视为明确提交的回答。

未指定时，默认采用学习模式，出五道中等难度的题，混合选择题、判断题和简答题。资料较短、无法支撑足够题目时，会减少题量并说明原因。你可以调整范围、题量、难度、题型、模式和输出格式。

简答题按核心含义评分，不要求措辞完全一致。完成后会给出逐题结果和需要复习的概念，也可以继续做针对这些概念的新题。

## 网页测验模板

默认仍采用对话形式。网页测验的 [HTML 模板](assets/quiz-template.html) 无需构建，可离线运行。代理先读取资料，再替换内嵌题目和界面文案；浏览器不提供 PDF 上传解析功能。附带示例基于本仓库的[贡献指南](../../CONTRIBUTING.md)。自定义方法见[模板数据指南](references/template-api.md)，视觉、交互和无障碍标准见[网页测验设计指南](references/web-quiz-design.md)。设计指南整合了 `frontend-design` 和 `ui-ux-pro-max` 的原则，无需单独安装这两个技能。

模板支持两种模式，自动评分选择题和判断题，简答题则通过参考答案对比和自行确认完成，不会声称简答题已由 AI 评分。答错的概念可通过后续新题复习，同时保留初次结果。数据仅在页面打开期间保留在内存中，不使用持久存储或外部服务。

## 资料与限制

- 使用可读取的文档、PDF、Markdown、网页、笔记和粘贴文本，并遵守指定范围。解析会标注实际核实的文档名、章节、页码或其他位置。
- 出题与评分以资料为依据，不编造来源位置，也不擅自用外部知识填补资料中的空缺。
- 能否读取资料取决于代理可用的工具。扫描版 PDF 可能需要 OCR。无法读取时，会请求可读取的资料或文本。
- 默认采用对话形式。不包含持久学习记录或考试认证，无需技能专用的 API 密钥或运行时。

工作流程见 [SKILL.md](SKILL.md)。
