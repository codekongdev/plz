# plz-quiz
[English](README.md) | 한국어 | [日本語](README.ja.md) | [简体中文](README.zh-CN.md)

내 문서로 만든 퀴즈를 풀면서 공부하거나, 정답을 보기 전에 학습한 내용을 확인합니다. Claude Code와 Codex에서 사용할 수 있으며, [plz](../../README.md)에 포함된 스킬입니다.

## 설치

아래 명령은 이 스킬이 저장소에 공개된 뒤 사용할 수 있습니다. 로컬 초안을 써 보려면 에이전트에게 `skills/plz-quiz/SKILL.md`를 직접 읽도록 요청하세요.

전역으로 설치:

```sh
npx skills add codekongdev/plz --skill plz-quiz -g
```

Codex에서 쓰려면 `-a codex`를 붙입니다. 아래 명령은 현재 프로젝트의 `.agents/skills/`에 설치합니다.

```sh
npx skills add codekongdev/plz --skill plz-quiz -a codex
```

## 사용법

문서를 제공하거나 노트를 붙여 넣은 뒤, 원하는 언어로 퀴즈를 요청하세요.

Claude Code:

```text
/plz-quiz Quiz me on these notes, one question at a time.
```

Codex:

```text
$plz-quiz Quiz me on these notes, one question at a time.
```

요청 예시:

- “이 PDF 2장으로 객관식 문제 10개 만들어 줘.”
- “이 문서를 이해했는지 확인해 줘. 다 풀기 전에는 정답을 보여 주지 마.”
- “용어 암기보다 개념을 실제 상황에 적용하는 문제로 내 줘.”
- “틀린 개념만 다른 문제로 다시 내 줘.”

## 학습·학습 확인 모드

- **학습:** 한 문제씩 답한 뒤 채점 결과, 짧은 해설, 문서 근거를 확인합니다. 필요하면 힌트를 요청할 수 있습니다.
- **학습 확인:** 답안 제출을 마친 뒤 점수, 정답, 해설을 확인합니다. 빠진 답이 있으면 채점 전에 확인하며, “모르겠어”는 명시적으로 제출한 응답으로 처리합니다.

별도로 지정하지 않으면 학습 모드, 5문항, 객관식·OX·단답형 혼합, 보통 난이도로 시작합니다. 짧은 자료로 충분한 문제를 만들 수 없다면 문항 수를 줄이고 이유를 안내합니다. 범위, 문항 수, 난이도, 유형, 모드, 출력 형식을 바꿀 수 있습니다.

단답형은 표현이 정확히 같은지보다 핵심 의미가 맞는지로 판단합니다. 풀이가 끝나면 문항별 결과와 다시 공부할 개념을 정리합니다. 해당 개념을 묻는 새 문제로 복습을 이어갈 수 있습니다.

## 웹 퀴즈 템플릿

기본은 대화형으로 유지합니다. 웹 퀴즈용 [HTML 템플릿](assets/quiz-template.html)은 빌드 없이 오프라인에서 실행됩니다. 에이전트가 먼저 자료를 읽고 내장된 문제와 UI 문구를 교체하며, 브라우저에서 PDF를 업로드해 읽는 기능은 없습니다. 기본 예시는 이 저장소의 [기여 가이드](../../CONTRIBUTING.md)를 바탕으로 만들었습니다. 교체 방법은 [템플릿 데이터 가이드](references/template-api.md), 시각·상호작용·접근성 기준은 [웹 퀴즈 디자인 가이드](references/web-quiz-design.md)를 참고하세요. 디자인 가이드는 `frontend-design`과 `ui-ux-pro-max`의 원칙을 정리한 것으로 두 스킬을 따로 설치할 필요는 없습니다.

템플릿은 두 모드를 지원하며 객관식·OX는 자동 채점하고, 단답형은 참고 답안과 비교해 직접 확인하도록 표시합니다. 단답형을 AI가 채점한 것으로 안내하지 않습니다. 틀린 개념은 후속 문제로 복습하되 초기 결과를 보존합니다. 데이터는 페이지를 열어 둔 동안 메모리에만 유지하며, 영구 저장이나 외부 서비스는 사용하지 않습니다.

## 자료와 제약

- 읽을 수 있는 문서, PDF, Markdown, 웹 문서, 노트, 붙여 넣은 텍스트 중 지정한 범위를 사용합니다. 해설에는 실제로 확인한 문서명·절·페이지 등의 위치를 표시합니다.
- 출제와 채점은 자료에 근거합니다. 출처 위치를 꾸며 내거나 자료에 없는 내용을 외부 지식으로 채워 넣지 않습니다.
- 자료를 읽는 기능은 에이전트가 사용할 수 있는 도구에 따라 달라집니다. 스캔 PDF는 OCR이 필요할 수 있습니다. 자료를 읽을 수 없으면 읽을 수 있는 자료나 텍스트를 요청합니다.
- 기본은 대화형입니다. 영구 학습 기록과 시험 인증은 포함되지 않습니다. 스킬 전용 API 키나 런타임은 필요하지 않습니다.

진행 절차는 [SKILL.md](SKILL.md)를 참고하세요.
