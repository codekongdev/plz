# plz-quiz
[English](README.md) | [한국어](README.ko.md) | 日本語 | [简体中文](README.zh-CN.md)

自分の資料をもとにしたクイズで学習したり、正解を見る前に理解度を確認したりできます。Claude Code と Codex に対応し、[plz](../../README.md) に含まれるスキルです。

## インストール

以下のコマンドは、このスキルがリポジトリで公開された後に利用できます。ローカルの草案を試すには、エージェントに `skills/plz-quiz/SKILL.md` を直接読むよう依頼してください。

グローバルにインストール:

```sh
npx skills add codekongdev/plz --skill plz-quiz -g
```

Codex では `-a codex` を付けます。以下のコマンドは現在のプロジェクトの `.agents/skills/` にインストールします。

```sh
npx skills add codekongdev/plz --skill plz-quiz -a codex
```

## 使い方

資料を渡すかノートを貼り付けて、使いたい言語でクイズを依頼してください。

Claude Code:

```text
/plz-quiz Quiz me on these notes, one question at a time.
```

Codex:

```text
$plz-quiz Quiz me on these notes, one question at a time.
```

依頼の例:

- 「この PDF の第 2 章から選択式の問題を 10 問作って。」
- 「この資料を理解できているか確認して。解き終わるまで正解は見せないで。」
- 「用語の暗記より、概念を実際の場面に応用する問題を出して。」
- 「間違えた概念について、別の問題を出して。」

## 学習・理解度確認モード

- **学習:** 1 問ずつ答えてから、判定、短い解説、資料の根拠を確認します。必要ならヒントを求められます。
- **理解度確認:** 解答の提出を終えてから、点数、正解、解説を確認します。未回答の問題は採点前に確認し、「わからない」は明示的な回答として扱います。

指定がなければ、学習モード、5 問、選択式・正誤式・短答式の混合、中程度の難易度で始めます。短い資料では問題数を減らし、その理由を伝えます。範囲、問題数、難易度、形式、モード、出力形式は変更できます。

短答式は、表現の完全一致ではなく意味にもとづいて判定します。終了時に問題ごとの結果と復習すべき概念をまとめます。その概念を問う新しい問題で復習を続けられます。

## Web クイズのテンプレート

標準は引き続き対話形式です。Web クイズ用の [HTML テンプレート](assets/quiz-template.html) はビルド不要で、オフラインで動作します。エージェントが先に資料を読み、埋め込まれた問題と UI 文言を差し替えます。ブラウザで PDF をアップロードして読み取る機能はありません。付属の例は、このリポジトリの[貢献ガイド](../../CONTRIBUTING.md)にもとづいています。変更方法は[テンプレートのデータガイド](references/template-api.md)、視覚・操作・アクセシビリティの基準は [Web クイズのデザインガイド](references/web-quiz-design.md)を参照してください。デザインガイドには `frontend-design` と `ui-ux-pro-max` の原則をまとめており、両スキルを別途インストールする必要はありません。

テンプレートは両モードに対応し、選択式・正誤式は自動採点、短答式は参考解答と比較して自己確認する形式です。短答式を AI が採点したようには表示しません。間違えた概念は別の問題で復習し、最初の結果は保持します。データはページを開いている間だけメモリに保持され、永続保存や外部サービスは使いません。

## 資料と制約

- 読み取れる文書、PDF、Markdown、Web ページ、ノート、貼り付けたテキストのうち、指定した範囲を使います。解説では、実際に確認できた文書名、節、ページなどの位置を示します。
- 出題と採点は資料にもとづきます。出典の位置を作り上げたり、資料にない内容を外部の知識で補ったりしません。
- 資料の読み取りは、エージェントが利用できるツールに依存します。スキャンした PDF には OCR が必要な場合があります。資料を読めない場合は、読み取れる資料やテキストを求めます。
- 標準は対話形式です。継続的な学習記録の保存や試験の認定は含まれません。スキル専用の API キーやランタイムは不要です。

手順は [SKILL.md](SKILL.md) を参照してください。
